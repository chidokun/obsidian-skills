# Zettelkasten Principles

> 🇬🇧 **Reference translation** of [`../Zettelkasten-Principles.md`](../Zettelkasten-Principles.md) (Vietnamese). The Vietnamese file is the source of truth.

Shared principles for every note produced by the Obsidian skills (`obsidian-doc-to-note`, `obsidian-explain-to-note`, `obsidian-socratic-learn`, `obsidian-feynman-learn`). Every note must follow these principles:

- **Atomic**: each note holds **exactly one idea**. If the source (a document or a topic) contains several ideas, split them into separate notes.
- **Write in your own words**: do not copy verbatim. Synthesize and rephrase so the user can understand it easily — the user will edit it later.
- **Linking**: actively look for existing notes in the Vault related to the idea and attach `[[wiki-link]]`s to them. Only link when a genuinely related note is found; never link to a note that does not exist.
